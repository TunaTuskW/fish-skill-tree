# UI/UX Design, Visual Systems & Frontend Suite (`design-frontend-suite`)

Unified product design and frontend engineering suite covering design systems, UI/UX conversion architecture, visual hierarchy, Apple Liquid Glass, advanced motion choreography, accessibility, and modern web standards.

## Bundled Skills
- `ui-ux-conversion-design`: Wireframing, UX user flows, SaaS dashboard density vs. landing page composition, component state matrices (loading/empty/error/success), and design token handoff.
- `design-system`: Extract tokens into `design-tokens.json` + CSS custom properties, generate `DESIGN.md` and interactive HTML previews, and run 10-dimension visual audits.
- `frontend-design-direction`: Domain-matched art direction, typography scales, color palettes, and anti-generic UI patterns.
- `liquid-glass-design`: Dynamic translucent materials, blur, specular highlights, and interactive morphing.
- `motion-advanced`: Purposeful micro-interactions, spring physics, View Transitions, and scroll-driven animations.
- `frontend-a11y`: WCAG AA/AAA contrast, keyboard navigation, focus traps, and ARIA semantics.
- `frontend-slides` & `ui-demo`: Interactive HTML slide decks and visual product showcases.
- `modern-web-guidance` & `chrome-extensions`: Modern CSS/HTML APIs (`<dialog>`, Popover, container queries, `:has()`) and Manifest V3 extensions.
