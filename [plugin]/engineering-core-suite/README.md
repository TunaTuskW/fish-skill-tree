# Core Engineering, Security & AI SDK Suite (`engineering-core-suite`)

Unified software engineering suite combining AST codebase graph exploration, database safety, zero-leak secret protection, context compression, and official AI SDK workflows.

## Bundled Skills
- `codegraph`: Tree-sitter knowledge graph initialization, architectural exploration, and blast-radius impact analysis.
- `database-assistant`: SQL schema inspection, transactional migrations, and `EXPLAIN ANALYZE` optimization.
- `sensitive-data-guard`: Pre-commit secret scanning (`scan_secrets.py`), `.gitignore` enforcement, and git history purging.
- `billion-context`: Multi-generational incremental context folding and `decompress-to-file` disk offloading.
- `google-antigravity-sdk`: Autonomous multi-agent orchestration using the Google Antigravity SDK.
- `gemini-api-dev`, `gemini-live-api-dev`, `gemini-omni-flash-api`: Official Gemini API text, multimodal, Live WebSocket, and video generation workflows (paired with the `gemini-api-docs` MCP server).
- `api-design`, `backend-patterns`: Production API design and backend engineering patterns.
