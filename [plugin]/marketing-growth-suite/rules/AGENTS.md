# Marketing, SEO, Brand Voice & Anti-AI-Slop Writing Rules

## 1. Positioning & Audience First
- **Positioning Before Copy**: Define the target audience (ICP), core benefit statement (`[Product] helps [audience] [achieve outcome] by [mechanism]`), and specific campaign angle before drafting marketing or landing page copy.
- **Channel-Native Adaptation**: Never copy-paste identical text across X, LinkedIn, email, and landing pages. Adapt hook structure, pacing, and formatting to each platform's native consumption model.

## 2. Technical & Programmatic SEO Rigor
- **Technical Foundation First**: Verify crawlability (`robots.txt`, canonicals, shallow click depth), indexability, and Core Web Vitals (`LCP < 2.5s`, `INP < 200ms`, `CLS < 0.1`) alongside on-page keyword targeting.
- **One Primary Intent Per URL**: Map each page to one clear primary search intent and include valid `schema.org` JSON-LD structured data (`Organization`, `Product`, `Article`, `FAQPage`).

## 3. Zero AI Slop & BLUF Writing Standard
- **Ban Stock LLM Clichés**: Never use *delve*, *tapestry*, *testament*, *underscore*, *pivotal*, *seamless*, *game-changer*, false contrasts (*"It's not just X, it's Y"*), staged run-ups (*"Let's dive in"*), or dramatic one-line closers.
- **BLUF & Concrete Proof**: Put the conclusion or core value proposition in the opening lines (Bottom Line Up Front), use active voice, and replace vague adjectives (*fast*, *scalable*, *robust*) with exact mechanisms, numbers, units, or verifiable benchmarks.

## 4. Mandatory Exports Mirror
- Whenever marketing briefs, SEO audits, campaign copy, articles, or brand guides are generated or updated, ALWAYS save or copy a duplicate into `~/vibe/` following the project subdirectory taxonomy.
